# Uso de IA y supervisión

El proyecto se desarrolla con asistencia de Codex. El alumno aporta el problema, experiencia profesional, requisitos de identidad, acciones y respuestas, protocolo TCP persistente, escalado y restricciones de presupuesto y equipamiento.

La asistencia se utiliza para concretar el contrato, crear código, configurar el despliegue y diseñar pruebas. El repositorio registra el desarrollo efectivo: no se reconstruye un historial ficticio.

Cada avance debe documentar qué se ha comprobado y qué sigue pendiente. Las pruebas del protocolo utilizan un vector HMAC independiente, casos de delimitación TCP y aritmética exacta. Las pruebas con PostgreSQL comprueban efectos persistidos, concurrencia, identidad e idempotencia. Los objetivos de carga de la especificación no se consideran resultados hasta medirlos.

El alumno deberá revisar y poder explicar código y decisiones. Antes de entregar se preparará una sesión de recorrido por protocolo, persistencia y réplicas, y una lista de pruebas que pueda repetir sin depender del chat.
